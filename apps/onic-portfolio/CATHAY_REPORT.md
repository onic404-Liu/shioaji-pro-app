# 國泰 CSV 未實現損益說明

首頁「國泰檔案未實現損益」位於永豐 API 未實現損益右方。數字依國泰台股、國泰複委託及檔案幣別分開呈現；TWD 與 USD 不相加，也不合併至永豐 API 損益。窄螢幕會換行，手機將此欄展開為整列。

「國泰未實現損益」分頁只讀原始 CSV，不修改、複製來源檔案，也不需要券商登入；仍須透過啟動器建立本機服務連線。檔案內容是匯出快照，並非即時行情。原檔未提供資料基準日，畫面顯示的修改時間只代表檔案修改時間，不代表持倉日期。

台股使用原檔「未實現損益」及「預估報酬率」；複委託使用「投資損益」及「報酬率%(不含息)」。系統不另扣費用、不換算匯率；若複委託檔包含其他幣別，也依幣別各自合計。缺少損益或未標示幣別時，相關合計顯示破折號，避免將不完整資料視為零。

資料來源選單可選全部、台股或複委託；搜尋比對匯出檔的「股票名稱」欄位，不分英文大小寫。若股票代號包含在該欄文字中，也能搜尋。篩選及搜尋僅改變明細列，首頁合計與來源卡片維持完整來源的合計。

本機服務回覆正常時，頁面會定期檢查檔案，也可按「重新讀取檔案」。讀取失敗時，已成功讀取過的來源保留上次結果並標示失敗；首次失敗的來源沒有舊數字可保留。快取只在本次本機服務及網頁執行期間存在，重新啟動後不能保證保留舊結果。

預設來源為上層 `投資對帳單／國泰證券／未實現損益`，亦可用 `ONIC_CATHAY_DIR` 指定目錄。支援 UTF-8 BOM 與 CP950 編碼。台股檔名為 `國泰未實現損益.csv`，複委託檔名為 `國泰 複委託 未實現損益.csv`。

本說明依 `cathay_files.py` 與 `web/app.js`、`web/app.css`、`web/index.html` 靜態檢查撰寫，未讀取真實財務來源。既有 `DESIGN.md` 視覺系統沿用；此說明不取代瀏覽器互動驗收及券商資料核對。
