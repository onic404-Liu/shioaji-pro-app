# Product
<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
延伸既有 Python Shioaji 專案：本機 Python HTTP 服務與 HTML/CSS/JavaScript，Windows 筆電使用。

## Users
使用者本人，查詢正式台股證券庫存、保存關注股票，並以持倉作為後續 B15 追蹤基礎。

## Capabilities and Constraints
- 目前功能：正式連線與帳戶、庫存與行情、關注清單、一般價格提醒、B15 追蹤位置。
- 新增國泰台股與複委託原始 CSV 未實現損益分頁，首頁在永豐損益右方呈現國泰檔案損益；不同來源及幣別分開，不合併成帳戶總損益。
- 正式環境唯讀；主程式拒絕模擬登入及所有下單路由。
- B15 判定與歷史加減碼紀錄尚未接入，一般價格門檻不代表 B15 策略。
- 使用者自行在本機輸入金鑰，不傳入對話。不把金鑰放進 OneDrive 專案資料夾。
- 正式查詢金鑰可保存在 Windows 認證管理員；亦可選擇僅在本次記憶體使用。
- 實際 API 操作、報價時效與官方測試審核須個別確認；離線驗證不代表帳戶已開通。

## Brand Commitments
亮色資產方向、台灣繁體中文、避免常見 AI 套版風格。以 Awwwards、Webby Awards、FWA 得獎作品的完成度為設計目標。此為品質目標，不是獲獎認證。

## Evidence on Hand
SDK 1.7.5；2026-10-05 已實測正式登入與 7 筆庫存、7 筆行情取得。假資料桌機／手機截圖及離線安全測試另行保留。舊桌面版、三方案預覽、模擬下單入口及 T4 文件已移出工作區封存。與券商畫面逐項核對及 Windows 金鑰實際保存仍須獨立驗證。

## Product Principles
金融數字保留來源和更新時間；失敗不可當成零庫存。正式資料與假資料預覽清楚區分。提醒用中性觀察語言。金鑰不得回傳至網頁或寫入專案設定。
